## The story

> Grandma's last voicemail still says hello.

Exactly six words, 42 characters. A grandchild keeps the voicemail because it is the last place her voice still says hello — a whole life of loss and love in one line, with the turn in the final word: she is gone, yet she still greets you.

## How it works

`main.py` (Python 3.13, standard library only) writes the story to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```

It refuses to write unless the text is exactly six words and 1–60 characters.
